# Solavisetech Women in Data - Cohort 3
## About the Program

The Solavisetech Women in Data program is a training cohort that helps women
build practical skills for a career in data.

Over the course of the program, participants learn the essential tools and
skills of a data professional: Excel for organizing and summarizing data, SQL
for querying databases, Power BI for building dashboards, and Python for
analysis and automation. Along the way, we practice data cleaning, data
analysis and data visualization to turn raw data into clear insights. Learning
happens through live sessions, weekly assignments and hands-on projects that
build a portfolio of real work.

- **Organizer:** Solavisetech
- **Cohort:** 3
- **Duration:** 12 weeks
- **Format:** Online 

## What I Aim to Achieve

By the end of the program, I aim to:

1. Build a strong foundation in data.
2. Complete several real-world data projects for my portfolio.
3. Be able to clean, analyze and present data in a way that supports decisions.
4. Publish my work on GitHub and showcase it to potential employers.
5. Grow my professional network through the cohort and mentors.
6. Gain confidents in showcasing my work.
